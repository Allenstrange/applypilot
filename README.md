# ApplyPilot

> AI job-application platform — tailor your CV and cover letters, scan ATS compatibility, and track applications. Now a Next.js app (v4); the original single-file version lives in [`legacy/`](./legacy).

## Status

Active development. See the `New-Features` branch for latest work.

## Features

- AI-powered CV tailoring and cover letter generation
- ATS compatibility checker
- Application tracker
- Multi-provider AI support (localStorage keys)
- PDF export

## Tech Stack

- Next.js
- TypeScript
- Zustand + localStorage
- jsPDF
- Tailwind
- Lucide icons

## Setup

```bash
git clone https://github.com/Allenstrange/applypilot.git
cd applypilot
npm install
npm run dev
```
